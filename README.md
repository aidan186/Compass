# Compass

Compass is a personal planning tool designed to help you organise your goals and decide what you want to focus on.

It allows you to list your goals and organise them by areas of your life, such as career, university, health and fitness, money, travel and personal goals.

## What Compass does

Compass helps you:

- Write down your goals
- Organise goals into different categories
- Decide when you want to achieve each goal
- Keep your priorities in one place
- Review what you want to work towards

## How to use Compass

1. Download the `W1_BOARD_AIDAN.xlsx` file from this repository.
2. Open the file in Microsoft Excel or upload it into Google Sheets.
3. Add your own goals to the spreadsheet.
4. Select the relevant category for each goal.
5. Choose the timeframe for when you want to achieve it.
6. Update the Compass as your goals and priorities change.

## Getting started

To use the tool yourself, download the Excel file included in this repository and replace the example goals with your own.

## About

This project was created as a simple way to turn personal goals into a clear and organised plan.
